# 测试机远程桌面连接（mstsc）快捷操作

## Goal

在测试机状态页的"申请占用"弹窗中新增"远程桌面连接"按钮：用户选定占用时长后，一键完成占用并打开本机系统自带的远程桌面连接（mstsc.exe），目标机器 IP 自动填入远程地址框；若浏览器无法直接拉起 mstsc，则自动将 IP 复制到剪贴板并引导用户直接粘贴。

## Requirements

- **按钮位置**：占用弹窗（申请占用 Modal）内，与"确认占用"并列新增"远程桌面连接"按钮。
- **时长必选**：弹窗打开时占用时长初始为"未选择"；未选择时长时，"确认占用"与"远程桌面连接"两个按钮均不可用（disabled）。选择时长后两个按钮同时可用。
- **远程连接一键流程**：点击"远程桌面连接"按钮后：
  - 自动执行占用操作（复用现有 `POST /api/test-machines/{id}/occupy` 接口，时长 = 当前所选时长，自动续期 = 当前开关状态），成功后机器自动置为 `busy`（占用者 = 当前用户），与"确认占用"行为一致；
  - 将机器 IP 复制到剪贴板（复用 `copyToClipboard` 三层方案）；
  - 尝试将 IP 填入本机 mstsc 远程地址框：通过生成并下载 `.rdp` 文件（内容含 `full address:s:<ip>`）触发——Windows 系统默认将 `.rdp` 文件关联到 mstsc，用户双击该文件即打开远程桌面连接且 IP 已填入；
  - 占用成功 + 文件生成后提示用户：IP 已复制到剪贴板，且已下载 `.rdp` 文件，可双击文件打开（IP 自动填入）或直接在 mstsc 中粘贴 IP。
- **失败处理**：占用失败（机器非空闲 / 被锁定 / 网络错误等）时不下载文件、不复制，仅提示接口返回的错误信息。
- **不改变现有行为**："确认占用"原有流程、倒计时、自动续期、心跳续期等逻辑保持不变。

## Acceptance Criteria

- [ ] 打开占用弹窗时无默认选中时长，"确认占用"与"远程桌面连接"按钮置灰不可点击
- [ ] 选择任意时长后，两个按钮同时变为可用
- [ ] 点击"远程桌面连接"：机器状态变为 `busy` 且占用者为当前用户；IP 已写入剪贴板；下载得到 `<机器名>.rdp` 文件，内容包含 `full address:s:<机器IP>`
- [ ] 在本机（Windows）双击下载的 `.rdp` 文件，打开 mstsc 且远程地址框自动填入该 IP
- [ ] 对非空闲 / 已锁定机器点击"远程桌面连接"，仅提示错误，不下载文件、不复制 IP
- [ ] 现有"确认占用"流程与提示文案不受影响

## Notes

- 纯前端改动，仅涉及 `frontend/src/pages/TestMachinePage.tsx`；后端占用接口已具备自动置 `busy` 能力，无需后端变更
- `.rdp` 是 Windows 标准远程桌面配置文件，系统默认关联 mstsc.exe；非 Windows 平台双击无效，但剪贴板提示文案通用，用户仍可直接粘贴
- 占用成功后机器自动为 `busy` 是后端既有行为（`occupy_test_machine` 中 `machine.status = "busy"`）
