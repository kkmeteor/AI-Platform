# 测试机远程用户名自动填入

## Goal

测试机新增"远程用户名"字段：添加测试机时可填写，后期可编辑修改；测试机卡片展示该字段；点击"远程桌面连接"生成 `.rdp` 文件时，将用户名写入文件，使 mstsc 打开后用户名自动填入。

## Requirements

- **数据模型**：`TestMachine` 新增可选字段 `rdp_username`（VARCHAR(100)），沿用 `teamviewer_id` 的既有处理模式（可空、不参与占用/锁定逻辑）。
- **数据库迁移**：启动时自动迁移（`migrate_db`）为存量库补充列；新库建表语句同步包含该列。
- **API**：`TestMachineCreate` / `TestMachineUpdate` / `TestMachineResponse` 均支持 `rdp_username`；创建/更新接口可写入，列表/详情接口返回。
- **添加/编辑弹窗**：新增"远程用户名（可选）"输入框，保存时提交；编辑回显。
- **卡片展示**：测试机卡片在 IP 地址下方展示"远程用户名"（仅当有值时显示）。
- **.rdp 文件**：生成时若 `rdp_username` 有值，写入 `username:s:<用户名>` 行（放在 `full address:s:` 之后）；无值则不写，保持现状。
- **不做密码**：本任务不涉及密码字段与自动填入（已决策搁置）。

## Acceptance Criteria

- [ ] 存量数据库启动后端后自动出现 `rdp_username` 列（无数据丢失）
- [ ] 添加测试机时可填写远程用户名，保存后列表/卡片展示该值
- [ ] 编辑测试机可修改远程用户名并保存生效
- [ ] 卡片展示"远程用户名"（有值才显示；无值不显示）
- [ ] 点击"远程桌面连接"下载的 `.rdp` 文件：有用户名时包含 `full address:s:<ip>` 与 `username:s:<user>` 两行；无用户名时仅 `full address:s:<ip>` 一行
- [ ] 占用/锁定/释放等既有流程不受影响

## Notes

- 字段命名 `rdp_username` 明确语义（远程桌面登录账号），与 `teamviewer_id` 并列
- 该字段不参与探针上报、占用校验等逻辑，仅作展示与 .rdp 生成数据源
