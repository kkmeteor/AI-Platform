# 局域网共享目录网页浏览与下载（File Manager）

## Goal

在 SinoAI Platform 网站中提供网页版文件管理器：登录用户可在浏览器中浏览局域网 SMB 共享目录（如 `\\10.10.11.31\SoftwareDev\tengfei\`，该共享需要身份认证）的内容，支持点击文件下载到本地、点击文件夹打包为 zip 下载。

## Requirements

- R1：网站侧边栏提供"文件管理"入口（Online 组导航项）。
- R2：浏览共享目录：进入共享根目录，展示文件夹与文件列表（名称、大小、修改时间），支持点击进入子目录、面包屑逐级返回。
- R3：点击文件可下载到本地；点击文件夹可打包为 zip 下载（zip 保留目录结构）。
- R4：后端通过 SMB 协议访问共享目录，**凭据复用登录用户的 AD 账号**：解密 `users.password` 的 base64 缓存密码建立 SMB 会话（NTLM）；用户改密码后需重新登录网站刷新缓存；缓存为空时提示重新登录。
- R5：所有登录用户均可使用该功能（JWT 认证），具体可见内容由共享目录 ACL 决定。
- R6：共享地址由配置提供：`smb.host` / `smb.share` / `smb.root`（config.json `smb` 段 + 环境变量覆盖）；域名复用 `ldap.domain`，可被 `smb.domain` 覆盖；未配置 host 时返回 503。
- R7：路径安全：仅接受相对路径，禁止绝对路径、`..`、前缀分隔符，防止路径穿越。

## Acceptance Criteria

- [ ] AC1：登录用户在侧边栏可看到"文件管理"入口并进入页面。
- [ ] AC2：可列出共享根目录内容，包含文件夹/文件、大小、修改时间，文件夹优先排序。
- [ ] AC3：点击文件夹进入子目录，面包屑可逐级返回上级直至根目录。
- [ ] AC4：点击文件可成功下载到本地，文件名（含中文）正确、内容一致。
- [ ] AC5：点击文件夹可打包为 zip 下载，zip 内目录结构与共享一致，可正常解压。
- [ ] AC6：未登录访问接口返回 401 并重定向登录页。
- [ ] AC7：共享不可达/凭据错误/路径不存在时，返回明确错误信息，前端有友好提示。
- [ ] AC8：路径穿越请求（如 `path=../..`）被拒绝。
- [ ] AC9：未配置 smb.host 时接口返回 503。

## Out of Scope

- 上传、删除、重命名、新建文件夹等写操作。
- 文件搜索、排序选项（固定：目录优先 + 名称排序）。
- 在线预览文件内容。
- 连接池 / 会话缓存（每次请求新建 SMB 连接）。
- 按用户白名单的网站侧权限控制（权限由 AD/共享 ACL 负责）。

## 已确认决策（用户拍板）

| # | 决策 | 结论 |
|---|------|------|
| Q1 | 凭据方案 | 复用登录用户的 AD 凭据（R4） |
| Q2 | 功能边界 | 浏览 + 单文件下载 + 目录 zip 打包；不做搜索/排序/写操作（R2/R3） |
| Q3 | 访问控制 | 所有登录用户可用，可见内容由共享 ACL 控制（R5） |
| Q4 | 前端入口 | 侧边栏导航项（R1） |
