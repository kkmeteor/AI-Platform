# TFS Changeset Query 使用示例

## 基础查询示例

### 1. 查询特定人员在指定时间段的提交

**用户输入：**
```
我要查询今年1月1号到5月26号，所有peng yang的提交结果
```

**解析结果：**
- startDate: "2026-01-01"
- endDate: "2026-05-26"
- submitter: "peng yang"

**输出格式：**
```markdown
## 查询结果

**查询条件：**
- 时间范围：2026-01-01 到 2026-05-26
- 提交人：peng yang

**统计：** 共找到 7 条提交记录

### 提交详情

1. **变更集 #24249**
   - 日期：2026-05-25 14:47
   - 描述：更新右屏 2.0.3.10199
   - 审核人：yangpeng
   - 关联Story/Bug：non

2. **变更集 #24238**
   - 日期：2026-05-25 10:25
   - 描述：离线重建界面设置重建时间列表，选中床位颜色缺失一块
   - 审核人：Guanwei.li
   - 关联Story/Bug：non
```

---

### 2. 查询所有提交（不筛选提交人）

**用户输入：**
```
查询2026年3月到5月的所有变更集
```

**解析结果：**
- startDate: "2026-03-01"
- endDate: "2026-05-31"
- submitter: 不指定

**输出：** 返回该时间段内所有人的提交记录

---

### 3. 查询最近时间的提交

**用户输入：**
```
查看shuo li最近一周的提交
```

**解析结果：**
- startDate: "2026-05-19"（假设今天是5月26日）
- endDate: "2026-05-26"
- submitter: "shuo li"

---

### 4. 查询特定月份的提交

**用户输入：**
```
查询guanwei li在2026年1月份的所有提交
```

**解析结果：**
- startDate: "2026-01-01"
- endDate: "2026-01-31"
- submitter: "guanwei li"

---

## 复杂查询示例

### 5. 跨季度查询

**用户输入：**
```
我要看peng yang从今年第一季度（1月到3月）的提交历史
```

**解析结果：**
- startDate: "2026-01-01"
- endDate: "2026-03-31"
- submitter: "peng yang"

---

### 6. 查询并统计

**用户输入：**
```
查询tianyu cai今年5月的提交，并统计数量
```

**解析结果：**
- startDate: "2026-05-01"
- endDate: "2026-05-31"
- submitter: "tianyu cai"

**额外处理：** 在结果末尾添加统计摘要
```markdown
### 统计摘要
- 总提交数：X 条
- 最早提交：2026-05-03 09:15
- 最新提交：2026-05-28 16:42
- 关联Story/Bug数量：X 个
```

---

### 7. 对比特定两人的提交

**用户输入：**
```
分别查询peng yang和shuo li在5月份的提交
```

**处理方式：** 
需要调用两次MCP工具：
1. 第一次：submitter = "peng yang"
2. 第二次：submitter = "shuo li"

然后对比展示结果。

## 自然语言日期解析

| 用户表达 | 解析结果 |
|---------|---------|
| "今年1月1号" | 2026-01-01 |
| "5月26号" | 2026-05-26 |
| "1月到5月" | 2026-01-01 到 2026-05-31 |
| "最近一周" | 2026-05-19 到 2026-05-26 |
| "最近一个月" | 2026-04-26 到 2026-05-26 |
| "上个月" | 2026-04-01 到 2026-04-30 |
| "本周" | 本周一到今天 |
| "本月" | 本月1号到今天 |

---

## 提交人姓名变体

系统会自动处理以下变体（不区分大小写）：

| 用户输入 | 匹配规则 |
|---------|---------|
| "peng yang" | Submitter.toLowerCase() === "peng yang" |
| "Peng Yang" | 同上 |
| "PENG YANG" | 同上 |
| "guanwei li" | Submitter.toLowerCase() === "guanwei li" 或 "guanwei.li" |
| "Guanwei Li" | 同上 |

## 错误场景示例

### 场景1：服务不可达
```
查询失败：无法连接到TFS服务
可能原因：
- TFS服务未启动
- 网络配置问题
请稍后重试或联系管理员。
```

### 场景2：无数据
```
未找到符合条件的提交记录

查询条件：
- 时间范围：2025-01-01 到 2025-12-31
- 提交人：test user

提示：该时间段内没有该用户的提交记录，请检查：
1. 日期范围是否正确
2. 提交人姓名是否正确
```

### 场景3：日期格式错误
```
日期格式不正确

期望格式：YYYY-MM-DD（如：2026-01-01）
请重新提供正确的日期范围。
```

## 高级用法

### 结合其他工具

可以先检查TFS服务状态，再查询：

**用户：** "先检查TFS服务是否正常，然后查询peng yang本周的提交"

**执行流程：**
1. 调用 `check_tfs_health` 工具
2. 如果服务健康，调用 `query_changeset_history`
3. 返回查询结果

---

### 定期查询模板

对于定期报告需求：

**用户：** "帮我生成本周团队提交报告"

**处理方式：**
1. 查询本周所有人的提交（不指定submitter）
2. 按提交人分组统计
3. 生成报告格式：

```markdown
# 团队周报 (2026-05-19 到 2026-05-26)

## 提交统计
- peng yang: 5 条提交
- guanwei li: 3 条提交
- shuo li: 2 条提交
- tianyu cai: 1 条提交

## 详细提交
[按人分组的详细列表]
```

---

## 提示和技巧

1. **精确姓名**：尽量使用完整的提交人姓名
2. **合理时间范围**：不要查询过长的时间段（建议不超过1年）
3. **灵活表达**：可以用自然语言描述日期，系统会自动解析
4. **多次查询**：需要对比或组合数据时，可以多次调用查询
5. **结果筛选**：查询返回后可以进一步按Description、Reviewer等字段筛选
